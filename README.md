# sql-proyectos

Proyectos avanzados de Tech Study Tracker para esta tecnología. Cada
carpeta es un proyecto independiente, con su propio `package.json` —
**entra en la carpeta (`cd <carpeta>`) antes de instalar dependencias**
o ejecutar nada.

## Proyectos

- [`inventario-transaccional`](./inventario-transaccional) — Inventario transaccional (SQLite) — transacciones reales, aislamiento y consistencia
- [`analitica-ventas-ventana`](./analitica-ventas-ventana) — Analítica de ventas con funciones de ventana
- [`catalogo-jerarquico-cte`](./catalogo-jerarquico-cte) — Catálogo jerárquico con CTE recursiva
- [`reportes-vistas-sql`](./reportes-vistas-sql) — Reportes de ventas con vistas SQL

La rama `main` de este repo tiene el punto de partida de cada proyecto
(con TODOs); la rama `solucion` tiene la implementación completa de
todos ellos, por si te atascas en alguno.
